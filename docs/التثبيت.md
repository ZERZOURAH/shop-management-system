# 📖 دليل التثبيت والإعداد

## المتطلبات الأساسية

- **Node.js**: إصدار 14 أو أحدث
- **PostgreSQL**: إصدار 12 أو أحدث
- **npm** أو **yarn**
- **Git**

## خطوات التثبيت

### 1. استنساخ المستودع

```bash
git clone https://github.com/ZERZOURAH/shop-management-system.git
cd shop-management-system
```

### 2. إعداد قاعدة البيانات

#### إنشاء قاعدة بيانات جديدة

```bash
# تسجيل الدخول إلى PostgreSQL
psql -U postgres

# إنشاء قاعدة البيانات
CREATE DATABASE قاعدة_المحل;

# إنشاء مستخدم
CREATE USER مستخدم_المحل WITH PASSWORD 'كلمة_السر_الآمنة';

# منح الصلاحيات
GRANT ALL PRIVILEGES ON DATABASE قاعدة_المحل TO مستخدم_المحل;
```

### 3. إعداد الخادم الخلفي

```bash
cd backend

# تثبيت المكتبات
npm install

# إنشاء ملف البيئة
cp .env.example .env

# تعديل ملف .env بإضافة بيانات قاعدة البيانات
# DB_HOST=localhost
# DB_USER=مستخدم_المحل
# DB_PASSWORD=كلمة_السر_الآمنة
# DB_NAME=قاعدة_المحل

# تشغيل الخادم
npm run dev
```

### 4. إعداد الواجهة الأمامية

```bash
cd frontend

# تثبيت المكتبات
npm install

# إنشاء ملف البيئة
cp .env.example .env

# تشغيل واجهة الويب
npm start
```

### 5. إعداد التطبيق الموبايل (اختياري)

```bash
cd mobile

# تثبيت المكتبات
npm install

# تشغيل التطبيق
npm start
```

## ✅ التحقق من التثبيت

1. تأكد من تشغيل الخادم على `http://localhost:5000`
2. تأكد من تشغيل واجهة الويب على `http://localhost:3000`
3. تأكد من الاتصال بقاعدة البيانات

## 🔧 استكشاف الأخطاء

### مشكلة: فشل الاتصال بقاعدة البيانات

```bash
# تحقق من أن PostgreSQL يعمل
psql -U postgres

# تحقق من بيانات الاتصال في .env
# تحقق من أن قاعدة البيانات موجودة
psql -U مستخدم_المحل -d قاعدة_المحل
```

### مشكلة: المنفذ مشغول

```bash
# غير المنفذ في .env أو استخدم
PORT=5001 npm run dev
```

### مشكلة: مشاكل مع npm

```bash
# حذف node_modules و package-lock.json
rm -rf node_modules package-lock.json

# إعادة التثبيت
npm install
```

## 📱 التشغيل على الهاتف

### نظام iOS

```bash
cd mobile
npm run ios
```

### نظام Android

```bash
cd mobile
npm run android
```
